BraTS 2020 Training Dataset
==========================

Download Link:
https://www.kaggle.com/datasets/awsaf49/brats2020-training-data?select=BraTS2020_training_data

Dataset Information:
- Source: Kaggle (awsaf49/brats2020-training-data)
- Format: HDF5 (.h5 slice files named volume_<id>_slice_<idx>.h5)
- Total Slices: 57,195 slices (369 patient volumes x 155 axial slices)
- Slice Resolution: 240 x 240 (4 MRI channels: T1, T1c, T2, FLAIR; 3 mask channels: Necrotic, Enhancing, Edema)

Setup Instructions:
1. Download and extract BraTS2020_training_data from the Kaggle link above.
2. Place it at BraTS2020_training_data/content/data (or pass --data-dir to src.train / src.evaluate).
3. Run training with patient-level splits:
   python -m src.train --data-dir BraTS2020_training_data/content/data
4. See model.ipynb for the archived v1 notebook run logs.

Note: Raw dataset files and trained weights are excluded via .gitignore due to file size.
